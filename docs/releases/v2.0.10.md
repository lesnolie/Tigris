# Tigris 2.0.10

## 中文

- 新增桌面动态壁纸：手机扫码上传视频，保留原画质，支持最高 4K 视频输入，单个文件最大 1 GiB。桌面静音循环，离开桌面、待机或播放开场动画时释放播放器；实际播放能力取决于电视解码器。
- 新增 Apple 航拍动态壁纸：兼容设备优先尝试 4K HEVC，不支持的片源或解码失败时降级，持续失败时显示静态背景。视频从 Apple 在线播放。
- 新增独立 Wallhaven 壁纸源：免密钥公开接口，手机可筛选关键词、分类、排序和最低 4K/1080p 分辨率。图片按需缓存，失败保留已有图片。Wallhaven 为静态图片源。
- 默认设置背景图、默认开场视频改为按需下载：电视设置和手机页面均可下载或删除。自定义上传优先；未下载时使用普通设置背景和 Tigris 字样。不再内置两项大素材，安装包约 2.2 MB，相比 2.0.9 的约 3.9 MB 减少约 45%。下载及上传的文件另占电视存储。
- MotionBGs 可在手机先下载作品页的 4K MP4，再上传为桌面壁纸；不支持直接粘贴作品网页或视频网址。

### 升级及验证

标准版使用 `Tigris-v2.0.10.apk`，Guard 版使用 `Tigris-guard-v2.0.10.apk`。
保持包名、官方签名及既有设置；versionCode 从 15 升为 16。直接覆盖升级，不卸载旧版。
发布流水线检查两种安装包与上一正式版的签名、版本、Android 要求及 HOME 声明一致性。

已完成代码检查、双版本单元测试/构建、语言检查、手机页面模拟接口交互和真实来源接口验证。
尚未实机验证 4K 播放流畅度、HDR、待机恢复、遥控器导航及手机到电视的完整上传链路；不新增型号兼容认证。

## English

- Home video wallpapers: upload original-quality video from the QR phone page, up to 4K input and 1 GiB per file. Silent looping on Home; playback releases on pause, standby and intro. Actual support depends on the TV decoder.
- Apple aerial Home wallpapers prefer 4K HEVC on capable hardware, fall back through lower-resolution sources, and use a static backdrop after repeated failures. Films stream from Apple.
- Dedicated Wallhaven public photo source with keyword, category, sort and minimum 4K/1080p controls. No API key required. Bounded caching retains photos on network failure.
- Default Settings artwork and welcome video are optional downloads, with download/remove controls on TV and phone. Custom uploads take priority; absent media uses the plain Settings background and Tigris wordmark. APK size is about 2.2 MB, roughly 45% below 2.0.9. Downloaded/uploaded media uses additional device storage.
- MotionBGs: download an MP4 on the phone, then upload it. Web-page and remote-video URL imports are not included.

Update in place with the matching Standard/Guard APK. Package ID and official signing identity are preserved; versionCode increases from 15 to 16. CI verifies both APKs against the previous official release before publishing.

Code, unit tests, builds, locale checks, phone UI with mock endpoints and live source endpoints were checked. Physical-TV 4K/HDR playback, smoothness, standby/wake, remote navigation and full phone-to-TV upload remain unverified; no new hardware certification is claimed.

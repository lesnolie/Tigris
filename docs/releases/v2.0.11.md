# Tigris 2.0.11

## 中文

- **动态壁纸 Dock 更跟手**：提高视频画面取样频率，并缩短液态玻璃贴图处理时间。Dock 保留玻璃效果，同时更及时透出视频内容，减少可见延迟。
- **更新流程可恢复**：软件更新显示下载进度；安装确认页可重新打开，卡住的待处理安装可取消后重试。
- **更新页面滚动修正**：右侧选项列表在标题下方的独立区域内滚动，避免挡住标题或裁切内容。

### 升级与验证

标准版使用 `Tigris-v2.0.11.apk`，Guard 版使用 `Tigris-guard-v2.0.11.apk`。保持包名、官方签名及现有设置；versionCode 从 16 升为 17，可直接覆盖升级，不必卸载旧版。

Android CI 已通过。动态壁纸 Dock 透明效果及更新页面滚动已在 Sony BRAVIA 实机检查；正式发布流水线会验证标准版和 Guard 版安装包的签名、版本信息及升级兼容性。

## English

- **More responsive Dock over live wallpapers:** More frequent video sampling and shorter glass-texture processing help the Dock show moving scenes sooner while retaining its liquid-glass appearance.
- **Recoverable updates:** Software updates show download progress. Reopen the system confirmation screen, or cancel a stuck pending install and retry.
- **Update-page scrolling:** The right-hand options list scrolls in its own viewport below the title, avoiding title overlap and clipped content.

### Upgrade and verification

Use `Tigris-v2.0.11.apk` for Standard or `Tigris-guard-v2.0.11.apk` for Guard. The package ID, official signing identity and existing settings are preserved. `versionCode` increases from 16 to 17, so install over the existing version without uninstalling it.

Android CI passed. The live-wallpaper Dock glass and update-page scrolling were checked on a Sony BRAVIA TV. The release workflow verifies both APKs' signing identity, version metadata and upgrade compatibility.

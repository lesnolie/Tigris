# Tigris v2.0.12

## 中文

本版继续聚焦两个目标：**外观和遥控器操作尽可能接近 tvOS**、**电视安装及 HOME 接管尽可能简单**。从官方 v2.0.11 升级，保持原有包名、官方签名和个人配置。

### 更新内容

- **Dock 5 或 6 个图标**：设置中可选，默认仍为 5 个；保留应用顺序和文件夹。维护者已手动测试 Dock 切换。
- **动态壁纸更流畅**：避免在主线程调用 `TextureView.getBitmap()`，使用异步 `PixelCopy`、有界低分辨率取帧、失败退避与缓存玻璃回退。保留 v2.0.11 的手机上传视频、航拍壁纸、Wallhaven、更新器和其他能力。
- **按电视和固件提供安装建议**：官网及中英文 README 明确 Standard 与兼容守护版 Guard 的区别。Sony / 一般 Android TV 首选 Standard；TCL / 雷鸟中拒绝 HOME APK 的固件使用 Guard；小米 / Redmi 等先诊断，不盲目停用原厂桌面。LG webOS 继续使用独立 IPK 预览包，Tizen / 原生 VIDAA 不支持 Android APK。
- **守护版更易区分**：应用显示名称改为「Tigris · 兼容守护版」，但文件名继续为 `Tigris-guard-v2.0.12.apk`，并保留包名、升级和数据兼容性。
- **说明清理**：README 顶部过时的旧版本公告已移除，历史版本的发行记录仍在 `docs/releases/`。

### 反馈与已知限制

Dock 已由项目维护者实测。动态壁纸取帧性能与各品牌实体 Home、开机、待机唤醒、长按 Home 清理内存的兼容性尚未完成跨机型实测。不同固件表现可能不同；欢迎在 Issues 提供电视型号、Android / MIUI / HyperOS 版本、Standard / Guard 包、复现步骤，以及是否能恢复原厂桌面。**安装 APK 成功不表示已接管实体 HOME**。本版本不自动禁用或卸载系统桌面。

### 安装与升级

- 标准版：`Tigris-v2.0.12.apk`
- 兼容守护版：`Tigris-guard-v2.0.12.apk`
- 校验文件：`SHA256SUMS-v2.0.12.txt`

Android 9+；versionCode **18**（v2.0.11 为 17）。请使用对应的现有版本覆盖升级，不要卸载以绕过签名错误。签名、升级检查和两个 APK 的构建由官方发布工作流完成。

## English

This release continues to focus on **tvOS-like visuals and remote-control interaction** and **simpler installation and HOME takeover** while keeping the official signing identity and user settings from v2.0.11.

- **Configurable 5/6-icon Dock:** Five remain the default; users can opt into six without resetting app order or folders. Dock configuration was manually tested by the project maintainer.
- **Asynchronous live wallpaper sampling:** Uses bounded `PixelCopy` rather than blocking the UI thread with `TextureView.getBitmap()`. Retains the existing uploaded MP4, Apple aerials, Wallhaven, updater and optional assets from v2.0.11.
- **Firmware-aware installer guidance:** README and site distinguish Standard from Compatibility Guard. Standard is the first choice on Sony / ordinary Android TV; some TCL / FFalcon firmware that rejects HOME APKs needs Guard. Xiaomi and other OEMs still require firmware-specific verification. The webOS IPK preview is separate; Tizen and native VIDAA cannot use Android APKs.
- **Guard application label:** `Tigris · Guard Mode`; APK filename remains `Tigris-guard-v2.0.12.apk` with the same package identity.
- **README cleanup:** Removed obsolete front-page announcements; historical release notes remain archived.

**Validation limits:** Dock received manual hardware testing. The asynchronous wallpaper optimization and brand-specific physical Home, boot, wake, and cleanup behavior still need user reports. APK installation is not proof of HOME takeover, and no system launcher is automatically disabled.

**Download:** `Tigris-v2.0.12.apk` (Standard), `Tigris-guard-v2.0.12.apk` (Compatibility Guard), `SHA256SUMS-v2.0.12.txt`; Android 9+, versionCode 18. Use an in-place upgrade with the matching official signed package.

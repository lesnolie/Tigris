# Tigris v2.0.13 — 按需安装 HGTV 与投屏 / On-demand Apps

## 中文

本版本基于 v2.0.12，继续聚焦 **tvOS 风格外观与遥控器操作** 和 **尽量简单、可恢复的安装体验**。

### 新功能

- **「应用与更新」tvOS 风格卡片**：Tigris、MiracastReceiver（投屏）和 HGTV（短剧）各有一张卡片，显示应用标识、用途、当前状态和下载进度。每张卡片只有一个主操作：「获取」「打开」「更新」；校验中显示状态，系统需要确认时显示「继续安装」，失败时才显示「重试」。
- **MiracastReceiver 投屏按需安装**：只在用户主动选择「获取」后才下载官方 `weekdayjast/MiracastReceiver` universal APK；安装后自动出现在普通应用列表，可自行加入 Dock。已有应用仍可检查更新。
- **HGTV 短剧按需安装**：从 `pan8664716/HGTV` 的 GitHub 正式 Release 获取官方 APK；首次安装前校验 SHA-256、APK 包名、签名和最低系统要求。该项目为独立第三方客户端，内容平台接口并非官方。
- **不预装、不强制推荐**：Tigris 主 APK 不包含这两个应用；不会因新用户打开桌面而自动下载安装，也不会自动占用 Dock。自动更新只处理已经安装的应用。
- **控制与反馈**：顶部保留「检查更新」，底部为「自动更新已安装应用」，系统安装权限缺失时才显示授权入口。进度和焦点逻辑经过自动化测试。

### 兼容与已知限制

HGTV 和 MiracastReceiver 是**独立第三方应用**。上游版本、内容接口或签名发生变化时，下载/安装可能被阻止；这是避免安装被替换 APK 的安全保护。Miracast/WFD 能否被 Windows `Win+K` 或 Android 系统发现，取决于电视固件的 Wi-Fi Display 能力，部分电视需要 Root；AirPlay / DLNA 与 Miracast 的要求不同。旧款 Android 电视、Sony/TCL/小米等实际使用体验有待贡献者反馈。**本版本完成编译与自动化测试，不代表这些功能已逐机通过电视实机测试。**

### 安装/升级

Android 9 及以上，versionCode **19**，从 v2.0.12 的 versionCode 18 正常递增。两个正式 APK 继续使用原官方包名和相同稳定签名，不要求卸载，不清理原有布局和设置。

- 标准版：`Tigris-v2.0.13.apk`
- 兼容守护版：`Tigris-guard-v2.0.13.apk`
- SHA-256：`SHA256SUMS-v2.0.13.txt`

### 反馈

请在 GitHub Issues 附上电视品牌型号、Android/固件版本、是否能下载 APK、安装提示、打开应用和投屏协议的实际结果。不要把安装成功等同于 HOME 接管成功。

## English

Version 2.0.13 builds on v2.0.12 and adds a **tvOS-style Apps & Updates** screen showing Tigris, MiracastReceiver casting and independent HGTV short dramas as individual cards. Each card has a single contextual action (Get, Open or Update); progress, PackageInstaller confirmation and Retry appear only when needed.

MiracastReceiver and HGTV are **optional standalone third-party APKs** retrieved from their respective GitHub Releases. Neither is bundled in Tigris, downloaded on first launch, or pinned to the Dock. New installations require an explicit user action, with release SHA-256, package identity and signing-certificate verification. Background auto-updates are limited to apps that are already installed.

HGTV's content APIs are unofficial and may change; Miracast/WFD capabilities depend on device firmware, sometimes requiring root or vendor support. These flows have passed automated code checks but **are not yet certified across physical TV models**. Please report your TV model, firmware, installation result, playback and casting behavior in Issues.

Android 9+, versionCode **19**, in-place upgrade with the existing signing identity. Assets: `Tigris-v2.0.13.apk`, `Tigris-guard-v2.0.13.apk`, `SHA256SUMS-v2.0.13.txt`.

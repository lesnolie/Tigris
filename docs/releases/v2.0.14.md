# Tigris v2.0.14 — 液态玻璃设置与蓝天欢迎 / Glass Settings & Sky Welcome

## 中文

- **统一液态玻璃界面**：「应用与更新」和 Settings 使用透明折射、圆角高光及连续焦点动画。两页默认共用当前主屏幕壁纸的柔化背景，自定义设置背景和图标仍可使用。
- **修复滚动底色跳动**：Settings 的玻璃逐帧采样屏幕上的背景，避免滚动结束后纹理突然换色。选中行完整显示，列表边缘柔和淡出。
- **设置交互更清楚**：可视开关、应用图标和勾选状态、玻璃弹窗及真实的关于详情；空列表不再伪装成可点击按钮。保留子页返回原入口的焦点，中英文与大字体可用。
- **首次使用欢迎动画**：蓝天白云背景，Tigris Logo 从第一笔写到最后，不添加欢迎语。写完显示下一步提示，按确认键进入桌面。首次确认后不再重复出现；设置中的「预览首次欢迎」可随时重播，不会重置首次使用状态。

### 安装与验证

Android 9+，versionCode **20**（上一版为 19）。沿用现有包名和正式签名，支持覆盖升级，保留布局、设置、应用数据及 Standard/Guard 类型。无需卸载。

两种安装包的构建、单元测试、静态检查及中英文资源检查通过；原生 Android TV 模拟器验证了中文、英文 1.3 倍字体、设置导航和欢迎动画状态。界面和欢迎动画已在 Sony BRAVIA 4K VH2（Android 12）展示验证。这不代表其它品牌、待机/重启或第三方投屏/短剧功能已完成逐机验收。

- 标准版：`Tigris-v2.0.14.apk`
- 兼容守护版：`Tigris-guard-v2.0.14.apk`
- 校验文件：`SHA256SUMS-v2.0.14.txt`

## English

- **Unified Liquid Glass UI:** Apps & Updates and Settings now share refracting glass, rounded highlights, continuous focus motion and a softened version of the current Home wallpaper. Uploaded Settings backgrounds and icons remain supported.
- **Smooth scrolling backgrounds:** Settings samples the screen background each frame instead of replacing stale row textures after scrolling stops. Focused rows stay fully visible within the fading list viewport.
- **Clearer settings:** Visual switches, app icons and checkbox states, glass dialogs, working About details and useful empty states. Subpages return focus to their opener; Chinese, English and larger text are supported.
- **First-use welcome:** A blue sky with soft white clouds and a Tigris logo drawn stroke by stroke, followed by a prompt to press OK and continue. The welcome completes once; Settings can replay it without resetting first-use state or changing boot-video preferences.

Android 9+, versionCode **20**. Standard and Guard retain the existing application ID, signing identity and upgrade behavior. Install over the matching existing flavor to preserve settings and data.

Both flavors passed builds, unit tests and static checks. Native Android TV tests covered Chinese, English at 1.3× text size and welcome state transitions. The UI and welcome were displayed on a Sony BRAVIA 4K VH2 running Android 12; other hardware, standby/reboot and third-party playback/casting are not newly certified by this release.

Assets: `Tigris-v2.0.14.apk`, `Tigris-guard-v2.0.14.apk`, `SHA256SUMS-v2.0.14.txt`.

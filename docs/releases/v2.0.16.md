# Tigris v2.0.16 — Sony controls and ADB diagnostics

## 中文

- **减少 Sony BRAVIA 反复注册弹窗**：后台读取音量、亮度、HDMI 与当前播放信息时不会主动调用注册接口。需要授权的显式写入才尝试注册；失败后记录 30 分钟退避，跨进程重启依然生效。已配对的 cookie 在有效期内可复用。
- **Sony HDMI 切换失败时安全回退**：BRAVIA 接口拒绝切换后，只在 Android 原生输入能够按物理 HDMI 端口号唯一对应时尝试直通切换；无法可靠匹配时引导到电视设置选择，不猜测端口。
- **ADB 授权排错更明确**：分别报告本机端口连接失败、调试密钥被拒、握手超时、协议不匹配和 shell 失败。已有残缺密钥不会被自动覆盖；未自动启用无线调试、绕过配对或获取新权限。
- **保留新版桌面守护**：合并 #61 时保留 v2.0.15 之后的 HomeGuardService、HOME alias/targetActivity 识别与 Top Shelf 设置，没有恢复旧版守护服务。
- 对应 PR [#61](https://github.com/lesnolie/Tigris/pull/61)，涉及 Issue #45、#47、#53、#54。**它们仍需反馈者的 Sony / HY300 真机复测，未作为已解决关闭。**

### 安装与验证

Android 9+，versionCode **22**（上一版为 21）。保持原应用包名和稳定签名，同类型 Standard / Guard 可覆盖升级，通常保留应用布局与设置；不要为了更新卸载旧版，也不要关闭原厂桌面。

CI 覆盖 Standard 和 Guard 的 JVM 单元测试、双语资源检查、安装器测试、Release APK 编译、Android Lint，以及发布环节的正式签名和升级兼容性检查。模拟与 CI 不代表所有 Sony 设备、HY300 或 HDMI 端口已经实机验收。

- 标准版：`Tigris-v2.0.16.apk`
- 兼容守护版：`Tigris-guard-v2.0.16.apk`
- 校验文件：`SHA256SUMS-v2.0.16.txt`

## English

- **Prevent repeated Sony BRAVIA registration prompts:** Background reads for volume, brightness, inputs and playing content do not initiate registration. Registration is reserved for explicit write operations, with a persistent 30-minute backoff after failure and cookie reuse when available.
- **Safe HDMI fallback on Sony:** When the BRAVIA switching API fails, Tigris attempts Android passthrough only if the physical HDMI port maps uniquely; otherwise, it opens TV settings for manual selection. It does not guess by input order or user label.
- **Clearer local ADB diagnostics:** Distinguishes connection failure, authorization rejection, handshake timeout, protocol mismatch and shell failure. Existing partial key pairs are preserved; there is no automatic pairing bypass or permission escalation.
- **Preserve current HOME guard architecture:** PR #61 was integrated without reverting the updated HomeGuardService, HOME alias/target resolution or Top Shelf settings introduced after v2.0.14.
- Related: [PR #61](https://github.com/lesnolie/Tigris/pull/61), issues #45, #47, #53 and #54. **Affected Sony and HY300 devices still need owner verification before those issues can be closed.**

Android 9+, versionCode **22** (previously 21). Standard and Guard keep the same application ID and official signing identity, allowing in-place upgrades of the corresponding flavor without removing the factory launcher.

CI covers tests, localization, installer contracts, release APK builds and lint. Publication also verifies the official signing certificate and compatibility with the previous release. CI and emulator evidence do not replace physical validation on affected devices.

Assets: `Tigris-v2.0.16.apk`, `Tigris-guard-v2.0.16.apk`, `SHA256SUMS-v2.0.16.txt`.

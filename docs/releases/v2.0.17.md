# Tigris v2.0.17 — Sony Android 9 sync permissions

## 中文

- **修复 Sony BRAVIA Android 9 同步设置权限异常**：`AndroidManifest.xml` 声明普通权限 `READ_SYNC_SETTINGS` 与 `WRITE_SYNC_SETTINGS`。`RevivalSync.ensure()` 调用 `getIsSyncable`、`setIsSyncable` 和 `setSyncAutomatically` 时，不再抛出 [#53](https://github.com/lesnolie/Tigris/issues/53) 实机日志中的 `SecurityException: no permission to read the sync settings`。
- **安装时自动授予**：两项均为 normal 权限，不增加运行时弹窗，也不需要 `pm grant`、ADB 或 root。
- **守护逻辑保持不变**：未修改 `RevivalSync`、桌面守护生命周期或 Standard / Guard 的安装方式。
- 对应 [PR #72](https://github.com/lesnolie/Tigris/pull/72)，只覆盖 Issue #53 里 Sony BRAVIA_ATV2_CN（国行 Android 9）的同步权限子问题。**实体主页键、开机、待机与无障碍恢复仍需该机复测，#53 保持开放。**

### 安装与验证

Android 9+，versionCode **23**（上一版为 22）。保持原应用包名和稳定签名，同类型 Standard / Guard 可覆盖升级，通常保留应用布局与设置；不要为了更新卸载旧版，也不要关闭原厂桌面。

CI 覆盖 Standard 和 Guard 的 JVM 单元测试、双语资源检查、安装器测试、Release APK 编译、Android Lint，以及发布环节的正式签名和升级兼容性检查。清单权限修复不代表 Sony BRAVIA_ATV2_CN 上的同步复活链路或 HOME 接管已经实机验收。

- 标准版：`Tigris-v2.0.17.apk`
- 兼容守护版：`Tigris-guard-v2.0.17.apk`
- 校验文件：`SHA256SUMS-v2.0.17.txt`

## English

- **Fix the Sony BRAVIA Android 9 sync-settings SecurityException:** `AndroidManifest.xml` declares the normal permissions `READ_SYNC_SETTINGS` and `WRITE_SYNC_SETTINGS`. `RevivalSync.ensure()` can call `getIsSyncable`, `setIsSyncable`, and `setSyncAutomatically` without the `SecurityException: no permission to read the sync settings` reported on [#53](https://github.com/lesnolie/Tigris/issues/53).
- **Granted at install:** Both permissions are normal. There is no new runtime prompt and no `pm grant`, ADB grant, or root requirement.
- **Guard behavior stays the same:** `RevivalSync`, the home-guard lifecycle, and the Standard / Guard installation paths are unchanged.
- Related: [PR #72](https://github.com/lesnolie/Tigris/pull/72). This covers only the missing sync-permission symptom in issue #53 on Sony BRAVIA_ATV2_CN (China, Android 9). **Physical Home, boot, wake, and accessibility revival still need a retest on that TV, so #53 stays open.**

Android 9+, versionCode **23** (previously 22). Standard and Guard keep the same application ID and official signing identity, allowing in-place upgrades of the corresponding flavor without removing the factory launcher.

CI covers tests, localization, installer contracts, release APK builds, and lint. Publication also verifies the official signing certificate and compatibility with the previous release. Declaring the permissions does not by itself verify sync revival or HOME takeover on BRAVIA_ATV2_CN.

Assets: `Tigris-v2.0.17.apk`, `Tigris-guard-v2.0.17.apk`, `SHA256SUMS-v2.0.17.txt`.

# Tigris v2.0.18

## 中文

- **没有安装确认页的电视（#73）**：应用内更新不再提交一个永远完不成的系统安装会话。校验过的 APK 会保存下来，更新卡片上显示路径和 `adb install -r` 命令。
- **相框只在主屏幕出现（#75）**：空闲计时只在 Tigris 主屏幕进行。投屏或正在播放视频时，不再被相框/屏保打断。
- **Android 9–11 唤醒时开机动画不再只有声音**：从待机唤醒后，动画会等显示状态变为亮屏、窗口获得焦点并画出一帧后再播放。Android 12 及以上仍使用原来的固定等待。Sony X9000H（Android 9）上已确认画面能出来。

### 安装与验证

Android 9+，versionCode **25**（上一正式版为 23，测试包为 24）。保持原应用包名和稳定签名，同类型 Standard / Guard 可覆盖升级；测试包也用 `adb install -r` 覆盖，不必卸载。不要关闭原厂桌面。

- 标准版：`Tigris-v2.0.18.apk`
- 兼容守护版：`Tigris-guard-v2.0.18.apk`
- 校验文件：`SHA256SUMS-v2.0.18.txt`

## English

- **TVs with no install confirmation page (#73):** the updater saves the verified APK and shows an `adb install -r` command instead of committing a session that cannot finish.
- **Photo frame only on the home screen (#75):** the idle timer runs on the Tigris home screen. Casting or video playback is no longer interrupted by the frame.
- **Wake animation on Android 9–11:** playback waits until the display is on, the window is focused, and a frame has been drawn. Android 12 and newer keep the fixed delay. Confirmed on a Sony X9000H.

Android 9+, versionCode **25** (previous official release was 23; test builds were 24). Standard and Guard keep the same application ID and signing identity. Install over the existing app with `adb install -r`.

Assets: `Tigris-v2.0.18.apk`, `Tigris-guard-v2.0.18.apk`, `SHA256SUMS-v2.0.18.txt`.

# Tigris v2.0.19

## 中文

- **更新安装不再卡在「继续安装」**：电视重启或更新中断后，继续安装会重新提交系统任务并取得新的确认页。等待确认时可选「强制重试」，只取消该应用的旧任务，复用校验通过的安装包或重新下载，保留已安装应用与数据。安装完成、任务丢失或进程退出后的状态也会重新核对。
- **修复空闲时跳过屏保、直接待机**：系统已启动的屏保不再被主屏幕的独立计时器误判并结束。在 Tigris 桌面、设置、更新和壁纸页空闲时都可正常响应系统屏保；继续保留对其他前台应用和播放内容的保护。
- **自动待机不会被误当成电源键关机**：开启「按遥控器电源键彻底关机」时，必须核实系统记录了最近的电源键休眠，且电视仍未唤醒，才执行关机。自动超时、HDMI、应用或未知原因不会触发彻底关机。

### 安装与验证

Android 9+，versionCode **26**。沿用原包名与稳定签名，Standard / Guard 均可对应类型覆盖升级，保留数据，也可覆盖本次 2.0.18 修复测试包。

- 标准版：`Tigris-v2.0.19.apk`
- 兼容守护版：`Tigris-guard-v2.0.19.apk`
- 校验文件：`SHA256SUMS-v2.0.19.txt`

Standard、Guard 各 158 项单元测试通过。Sony BRAVIA 4K VH2 / Android 12 已验证桌面与设置页自然超时进入并保持照片屏保，测试后恢复原十分钟设置；安装中断、重启后继续安装、强制重试及成功状态回调在独立 Android TV 模拟器中验证。没有执行电视物理电源键的彻底关机测试。

## English

- **Recover interrupted installations:** Continue now recommits the owned system session after a reboot or interruption and obtains a fresh confirmation page. Force retry replaces the old task, reuses a verified APK when available, and preserves the installed application and data. Installed versions and missing or interrupted tasks are reconciled when returning to Updates.
- **Show the screensaver instead of immediately entering standby:** a system-started dream no longer rechecks Home's independent idle timer and exits during the focus transition. Idle Tigris Home, Settings, Updates and Wallpaper pages can use the system screensaver; foreign foreground applications and active playback remain protected.
- **Do not mistake automatic standby for a power-key shutdown:** optional full shutdown requires a recent system-confirmed power-button sleep while the display remains non-interactive. Timeout, HDMI, application and unknown sleep reasons do not trigger full shutdown; waking the TV invalidates a queued check.

Android 9+, versionCode **26**, same application ID and stable signing certificate. Upgrade in place with the matching Standard or Guard APK, including from the 2.0.18 recovery test builds.

Validation: 158 unit tests per flavor. Natural idle screensaver behavior on Home and Settings was verified on Sony BRAVIA 4K VH2 / Android 12. Installation recovery and completion callbacks were exercised in an isolated Android TV emulator. Physical full shutdown via the remote was not tested.

Assets: `Tigris-v2.0.19.apk`, `Tigris-guard-v2.0.19.apk`, `SHA256SUMS-v2.0.19.txt`.

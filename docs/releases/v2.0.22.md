# Tigris v2.0.22

## 中文

继 [v2.0.21](v2.0.21.md) 的更新安装与相框屏保修复之后，本版进一步改善 **App 图标的视觉质量**，同时纳入已合并的 [#86](https://github.com/lesnolie/Tigris/pull/86) 极致液态玻璃功能。

- **TV Banner 优先、尽量不裁剪：** 对接近 16:9 的高清电视横幅保留充满卡片的效果；对方形、超宽或特殊比例的横幅改为等比居中显示，保留完整 Logo 和边缘文字，不再统一强制居中裁剪。过小的横幅改用 App 图标兜底。
- **方形图标更清楚：** 无横幅应用不再把小尺寸图标放大模糊铺满背景；改用提取自原图标的克制色彩渐变、256px 渲染后清晰缩放的居中图标。保持原生色彩及造型，不生成仿冒的品牌素材。
- **现有操作不变：** 保留 16:9 卡片、5/6 列 Dock、文件夹、图标顺序、圆角、tvOS 焦点放大、投影与高光动效。
- **可选极致液态玻璃：** 静态壁纸上使用折射、色散和自适应着色；动态壁纸下可启用透明 Dock 和控制中心，减少低帧率背景截图产生的拖影；可按电视性能关闭。该选项**默认关闭**，不强制低性能设备使用。
- **继承 v2.0.21 修复：** Sony 系统安装确认、缓存的更新信息、HGTV 数字标签，以及相框抢在自动休眠之前启动、设置页空闲/暂停视频可进入、投屏或播放时禁止屏保。详细机制和权限限制见 [v2.0.21 更新说明](v2.0.21.md)。

### 安装与兼容

Android 9+，**versionCode 29**（v2.0.21 为 28）。保持原应用 ID 和稳定签名。下载与现有安装类型一致的 Standard 或 Guard APK 覆盖升级，不卸载、不清除数据，不禁用原厂桌面。

- 标准版：`Tigris-v2.0.22.apk`
- 兼容守护版：`Tigris-guard-v2.0.22.apk`
- SHA-256：`SHA256SUMS-v2.0.22.txt`

### 验证说明

代码包含 TV Banner 比例、裁剪边界、图标尺寸和低分辨率兜底的单元测试。正式发布工作流检验 Standard/Guard 测试、APK 构建、Lint、稳定签名与上一正式版覆盖升级兼容性。各厂商 App 的图标素材质量不完全一致，屏保/投屏行为及极致玻璃在具体机型上仍需实机确认。

## English

Following the updater and idle photo-frame fixes in [v2.0.21](v2.0.21.md), this release improves **application tile artwork** and includes the optional extreme-glass feature merged in [#86](https://github.com/lesnolie/Tigris/pull/86).

- **Respect TV banners:** Near-16:9 TV artwork fills the tile; unusually tall, square and panoramic banners use aspect-preserving fit rather than cutting off logos. Tiny banners fall back to the native app icon.
- **Cleaner square-icon fallback:** Replace enlarged, blurred duplicates with a restrained accent-tinted gradient, rendering the native icon at 256px before downscaling it to a consistent central position. No proprietary artwork is fabricated or bundled.
- **Keep the tvOS layout:** 16:9 tile sizing, 5/6-column Dock, ordering, folders, corner radius and focus scale/tilt/glint/shadow remain.
- **Optional extreme Liquid Glass:** Enhanced refraction and color adaptation on static wallpapers; transparent video Dock/Control Center on moving wallpapers without low-frequency blurred snapshots. **Off by default** and reversible for lower-powered devices.
- **Includes v2.0.21 repairs:** Real Sony PackageInstaller confirmation, cached update metadata, numeric HGTV release tags, earlier-than-sleep photo-frame scheduling, and safeguards for active playback or casting. See [v2.0.21 notes](v2.0.21.md) for supported scenarios and limitations.

### Installation

Android 9+, **versionCode 29** (v2.0.21: 28), same application ID and stable release signer. Upgrade in place with the matching flavor, preserving app data and the stock launcher.

- Standard: `Tigris-v2.0.22.apk`
- Compatibility Guard: `Tigris-guard-v2.0.22.apk`
- Checksums: `SHA256SUMS-v2.0.22.txt`

### Validation

Adds JVM regression tests for TV banner geometry, cropping/containment boundaries, icon sizing and tiny-banner fallback. The official release workflow checks Standard/Guard unit tests, APK builds, lint, stable signing, and in-place upgrade compatibility. Third-party icon assets vary by source; vendor-specific screensaver/casting and extreme-glass behavior still need real-TV acceptance.

# Tigris v2.0.23

## 中文

- **统一相框时间：** 接管成功并完成本地调试、使用情况访问和设置写入授权后，默认让 Android 系统屏保也采用 Tigris 的「空闲多久显示相框」。不再保留独立的标准 Android 自动睡眠/注意力超时；底层仍由系统触发屏保，不使用后台高频轮询。
- **先接管，后生效：** 普通应用模式不改计时。原生默认 HOME 或守护实际带回 Tigris 后才允许生效；已知会虚报默认 HOME 的小米/TCL 必须走实际守护路径。设置页可查看是否仍在等待接管/授权，也可关闭统一计时。
- **可还原：** 修改前保存原值；关闭统一计时、关闭相框或失去接管后尝试还原。保留用户后来在系统设置中的修改。写入被拒绝或写后读回不符会回滚，保留未能还原的记录以便重试；安装器的 restore 同步关闭统一计时。
- **暂停屏保识别：** 忽略屏保自己的 DreamActivity 前台事件；普通媒体接口无结果时，只通过已经授权的本地 ADB 读取媒体会话，并在后台执行。明确暂停的前台播放器可进入相框；播放和投屏继续避让。统一模式拒绝屏保时刷新唤醒事件，避免退出屏保后直接因空闲而睡眠。

### 兼容范围与验证

只管理 Android 标准设置。不停用原厂桌面，不猜测或修改厂商私有定时器；原厂节能策略、HDMI-CEC、关机预约等不是本功能的覆盖范围。缺权限或无法证实接管时不启用。无法识别的第三方播放状态不视为暂停。

包含 Standard/Guard 单元测试、事务回滚/拒写/读回不符/原值缺失/用户后续修改测试、安装器与升级兼容性检查。Sony BRAVIA 4K VH2 的具体硬件观察记录见 [验证说明](../paused-video-dream-verification.md)。其他机型与长时间播放/投屏仍需实机验收；不宣称所有电视均已验证。

Android 9+，versionCode **30**；保持原应用 ID、两种安装类型和稳定签名。对应类型覆盖升级保留数据。

- Standard: `Tigris-v2.0.23.apk`
- Guard: `Tigris-guard-v2.0.23.apk`
- SHA-256: `SHA256SUMS-v2.0.23.txt`

## English

Unified idle timing defaults on only after HOME takeover and the required existing local ADB, usage-access and settings permissions. Android dream timing follows the Tigris photo-frame duration; separate standard sleep/attentive deadlines are disabled. Normal app mode leaves timers alone. Known Xiaomi/TCL default-HOME false positives require the observed Guard return path.

Original standard settings are journaled before mutation, verified by readback and restored on opt-out, frame disable or lost takeover. Denied/ignored writes roll back; later user edits are preserved. Installer restore opts out before returning HOME. Vendor-private timers, factory packages, HDMI-CEC and scheduled power-off are not modified.

Dream foreground tracking ignores Android DreamActivity. An already authorized local shell provides a background media-state fallback when the normal API is empty. Only a confirmed paused foreground player is eligible; active playback and casting remain excluded. Managed dream rejection refreshes wake activity to avoid immediately sleeping at the elapsed idle deadline.

Android 9+, versionCode **30**, matching Standard/Guard upgrades with the existing signing identity. Automated checks cover both flavors, ownership rollback and installer contracts. Sony observations are documented separately; other TVs and prolonged playback/casting remain hardware-unverified.

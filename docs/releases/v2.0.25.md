# Tigris v2.0.25

## 中文

- **投屏更新恢复：** 上游 MiracastReceiver v1.2.14 把包名从 `com.weekd.miracastreceiver` 改成 `top.jast.miracastreceiver`，Tigris 原来固定的包名校验会把它当成「安装包身份不符」直接拒绝。更新中心现在按新包名检查、安装与打开，并继续使用上游同一签名 `ea7f4568203d294bd37acac966d6d707f79147549d24c2244f58a6fbc27a6291` 和 `miracast-receiver-vX.Y.Z-universal.apk` 文件规则。
- **旧版迁移：** 电视上还装着 1.2.13 或更早的旧包名时，投屏卡片不再显示注定失败的「更新」，而是显示「卸载旧版」；按提示在系统卸载页确认后，再点安装即可。上游明确说明包名变更后旧应用数据不会迁移，因此这里不假装能保留设置。
- **投屏不再被相框盖住：** 新包名加入投屏接收器识别名单，投屏或 AirPlay 连接期间相框屏保继续避让；旧包名也保留识别，升级前后行为一致。新包名同时加入内存清理保留名单。
- 本版只改更新与投屏识别，不修改桌面、玻璃外观或屏保计时。Android 9+，versionCode **32**；Standard / Guard 使用原签名覆盖升级，保留数据。

- Standard: `Tigris-v2.0.25.apk`
- Guard: `Tigris-guard-v2.0.25.apk`
- SHA-256: `SHA256SUMS-v2.0.25.txt`

## English

- **Casting updates work again:** upstream MiracastReceiver v1.2.14 renamed its package from `com.weekd.miracastreceiver` to `top.jast.miracastreceiver`. Tigris pinned the old identity, so the update center rejected the official APK with "package identity mismatch". It now checks, installs and opens the new package, still pinned to the upstream signing key `ea7f4568203d294bd37acac966d6d707f79147549d24c2244f58a6fbc27a6291` and the `miracast-receiver-vX.Y.Z-universal.apk` asset rule.
- **Old install migration:** when 1.2.13 or older (the pre-rename package) is present, the casting card offers **Uninstall old** instead of an update that can never succeed. Confirm in the system uninstaller, then install the new package. Upstream documents that app data is not migrated across the rename, so Tigris does not pretend settings survive.
- **No screensaver over casting:** the new package is recognized as a casting receiver, so the photo-frame screensaver keeps yielding during Miracast and AirPlay sessions. The legacy package stays listed too, and the new package is added to the memory-cleanup keep list.
- This release only changes update and casting detection; the home screen, glass rendering and screensaver timing are untouched. Android 9+, versionCode **32**; matching Standard/Guard upgrades keep the existing signing identity and user data.

- Standard: `Tigris-v2.0.25.apk`
- Guard: `Tigris-guard-v2.0.25.apk`
- SHA-256: `SHA256SUMS-v2.0.25.txt`

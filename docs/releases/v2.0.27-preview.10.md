# Tigris v2.0.27 Preview 10 — Reduced tvOS Feature Set

> **Preview release / 开发预览版，供用户自行验证。** Built from the isolated preview branch. Stable `main` and v2.0.26 remain unchanged.

## 中文

### 本版主动移除（用户确认不需要）

- **PIN 防护**：删除 Tigris 内置 PIN 设置、应用启动拦截、管理页面、Manifest 注册、双语字符串和专用测试；不影响 Android 系统 PIN 或其他设备设置，也不清空其他已有偏好。

- **搜索**：删除独立的已安装应用搜索与语音搜索页面、入口、字符串和相关引用。
- **多用户隔离**：删除三套独立桌面配置及切换入口；应用顺序、隐藏列表和文件夹统一恢复使用原有单桌面的设置键。**不删除已有用户存储的数据**。
- **AirPlay 接收端入口**：删除新增的外部 AirPlay 项目安装二维码/入口和相关字符串。之前正式版已有的独立 **MiracastReceiver / HGTV 按需安装与更新模块保持不变**，没有顺手删除这些已有功能。
- **手机输入**：删除仅供搜索使用的二维码配对键盘与临时局域网服务。原本用于上传壁纸、头像、欢迎视频的 `PhoneServer` 继续保留，不属于本次新增搜索输入。
- 控制中心不再出现搜索、多用户或 AirPlay；保持 **控制 / 正在播放（有媒体会话时）/ 快捷操作** 三类，快捷操作包含最近应用、电视系统设置。

### P2 Top Shelf — 交互与性能

- **遥控器浏览**：Dock 聚焦、Top Shelf 展示时，按上键进入推荐浏览；左右键切换内容，确定键打开同一 App 支持的 HTTPS 内容链接（不支持时只启动 App），下键或返回键退出浏览。
- **旧请求丢弃**：每个焦点会话和图片请求使用版本号，焦点快速切换或手动浏览后，过期网络结果不再覆盖新内容。
- **有界后台任务**：最多两个图片加载线程，四个排队请求；快速连按优先保留最新请求，避免后台任务队列无限增长。
- **图片性能**：增加内存 LRU（按可用堆限制），图片下载使用唯一临时文件与 SHA-256 文件名；减少重复解码，磁盘最多留 40 张已下载图片。
- **图片切换清理**：中断动画时移除旧 View，避免不断叠加图片引用；仍保留原有 tvOS 风格渐变与玻璃效果。
- **内容跳转**：Bilibili 的 BV 号与斗鱼房间号在严格格式验证后生成 HTTPS 内容链接，只有对应 App 真正支持时才打开该内容，否则进入 App。
- **回归测试**：补充导航循环、过期回调丢弃、图片缓存键和内容 ID 验证测试。保留自定义 JSON、15 分钟内容缓存及无内容时的普通桌面回退。

### P1 原生优先、Tigris 兜底

- **不按品牌判断**：Sony、TCL、小米等统一采用能力检测，不使用品牌白名单或冒险调用私有 Activity。
- **原生优先**：仅当用户已启用 Tigris 现有无障碍服务，且 Android 能调用 `GLOBAL_ACTION_RECENTS` 时打开系统原生任务切换器。
- **能力查询**：Android 11+ 使用 `getSystemActions()` 检查当前系统是否公布 Recents 操作；Android 9/10 因无查询 API，仅在现有服务已连接时尝试 `performGlobalAction` 并判断返回结果。
- **兜底**：服务未启用、系统未公布原生切换操作或调用失败时，直接打开 Tigris 自己的应用切换器。
- **统一入口**：桌面 App Switch 键、双击 Home、控制中心、设置页均经过相同路由。
- **无新增权限**：不会自动开启无障碍、不会尝试通过 ADB 注入按键；Sony 原生切换器能否被调用仍需机型实测。

### P1 应用切换器：遥控器交互

- **遥控器横向切换**：加大应用卡片，左右移动焦点时自动将卡片平滑滚入视野，并使用放大、上浮、描边和阴影突出选中项。
- **确定打开应用**：继续通过 Android 公开启动 Intent 返回所选应用，实际任务状态恢复取决于目标应用自身的启动模式。
- **向上移除卡片**：遥控器向上键仅移除 Tigris 切换器卡片，并在用户下次主动打开应用前保持隐藏；不宣称结束第三方 Android 任务。
- **返回/关闭页面**：沿用 Activity 的系统返回行为，不截获系统级全局按键。
- **不需要系统权限或任务截图**：第三方 Android TV 桌面无法跨应用获取完整任务快照、强制结束任务，相关能力不以假截图伪装。

### 最近应用性能优化

- **打开即显示**：先读取 Tigris 本地启动历史，不再等待系统使用记录扫描。
- **避免卡顿**：可选 UsageStats 过去两天记录改为后台线程处理，主线程不再扫描/排序事件。
- **稳定遥控器操作**：用户一旦开始按键，后台结果不会突然重排正在选中的卡片；Activity 退出后不更新界面。
- **有界内存**：按可用应用保留每个包最后一次前台时间，不累积大量事件；只显示最多 12 个仍可启动的应用。
- **回归测试**：新增排序去重、卸载应用过滤、无使用记录权限回退、卡片数量上限测试。

### 保留并开发的 tvOS 风格功能

- 通用自动图标：合格的 Android TV Banner → 可安全分层的 Adaptive Icon → 原始 Launcher Icon → 占位符；保留品牌比例与配色，缓存与单 App 图标来源覆盖。
- 5:3 与 16:9 卡片比例切换，以及 v2.0.26 经典浅灰卡片回退。
- 硬件加速方向感知焦点动画：放大、浮起、3D 倾斜、动态高光、阴影、兼容的 Adaptive 图层视差；快速遥控器输入可中断。
- 最近应用卡片切换，及默认关闭、受机型按键分发限制的可选双击 Home。
- Now Playing：用户授权的 MediaSession 元数据、播放／暂停、前一首／后一首（仅在对方应用支持时显示）。
- Top Shelf：Bilibili、Douyu、一个自定义 JSON 源、可安全路由到同一 App 的 HTTPS 内容链接。
- 电视设置入口：使用 Android 官方系统设置 Intent，不越权修改电视固件配置。
- 本地文字缩放：90% / 100% / 115% / 130%。
- 继续保留旧版桌面编辑、文件夹、Dock、壁纸、相框/航拍屏保、开机动画、守护和系统兼容等现有能力。

### 兼容与验收

- Standard、Guard：versionCode **43**，versionName **2.0.27-pre10**。原正式签名覆盖对应版本升级。
- 从 Sony Android TV 和其他 Android 9+ 设备可安装性角度执行 CI、JVM 测试、两种 Release APK 编译、Lint、签名和升级检查。
- **Sony 真机 FPS、录屏和使用体验由用户自行验证**。CI 通过不代表所有厂商上的系统键与媒体功能都可用。
- 不修改 Android 厂商原生 HOME，不合并 main，不替换正式版。

## English

### Explicit removals

The optional **Tigris-local PIN/app restrictions** are removed end-to-end (implementation, launch guards, settings/UI, manifest, bilingual strings and tests). This does not affect Android's system PIN or other device settings. Existing unrelated preferences remain untouched.


At the user's direction, remove **installed-app Search/voice Search**, **the three isolated local launcher profiles**, **the newly introduced optional AirPlay setup**, and **the temporary QR-paired phone Search keyboard**. Delete code, controls, manifest entries and unused resources for those modules.

**Do not remove existing, unrelated stable features:** the optional MiracastReceiver/HGTV update services, the previously implemented phone asset-upload server, app folders, and genuine recent-app cards. Keep original preference and folder keys compatible with previous stable layouts.

### P2 Top Shelf — navigation and performance

With a supported dock app focused and Top Shelf visible, D-pad Up enters content browsing; Left/Right selects a feature, OK launches a package-scoped HTTPS deep link only when the same app resolves it (otherwise launches the app), and Down/Back exits without disrupting the dock. Generation-gated focus and image loads discard obsolete work; a bounded two-worker queue drops outdated requests under fast remote input. A memory-budgeted LRU cache avoids repeated image decoding, SHA-256 disk filenames avoid Java-hash collisions, unique temporary filenames avoid concurrent writes, and interrupted cross-fades release old views. Built-in Bilibili BV and Douyu room identifiers are format-validated before constructing links. Added pure unit tests for navigation, stale responses, identifiers, and cache-key uniqueness. Existing feeds, custom JSON, expiry policy and normal-home fallback are retained. The TV-specific visual experience and deep-link resolver behavior still require real-device testing.

### P1 native-first switching, local fallback

Each launcher entry point (App Switch key delivered to the app, double Home, Control Center and Settings) uses one capability-based router. It prefers Android's global Recents action only through Tigris's already enabled accessibility service. On Android 11+ the service checks `getSystemActions()`; on Android 9/10 it can try the action and rely on the system's return value. A missing service, unsupported action or unsuccessful call falls back to Tigris's local card switcher. This is **not** a universal native Recents detector; an unprivileged launcher cannot force-enable accessibility or assume a Sony-specific implementation. No additional permissions, undocumented OEM activities or injected key events are used. JVM tests cover the capability policy.

### P1 App Switcher remote navigation

Larger horizontally browsable app cards now center on directional focus, with scale, elevation and a highlight. Press OK to launch the selected application, or D-pad Up to remove only that card from the Tigris switcher; it is restored on the next explicit launch. This does **not** terminate another application's Android task, and no fake live snapshots or privileged APIs are claimed. New unit tests cover dismissed-card filtering and a deliberate relaunch.

### Recent Apps performance and reliability

The App Switcher immediately renders locally recorded launches, then optionally enriches history from Android UsageStats on a background thread. Scans keep only one timestamp per currently launchable package, cap the UI at 12 cards, filter removed apps, and never reorder the focused cards after remote interaction. No privileged task snapshots or new permissions are introduced. Pure JVM regression tests cover ordering, de-duplication, package filtering, and permission-independent fallback. Corrects the preview workflow's APK version-code assertion to 40 for Preview 10.

### Included features

- Automatic Android TV banner/adaptive icon/launcher icon/fallback rendering with brand-aware landscape cards, 5:3/16:9, classic grey mode, caching and per-app override.
- Directional GPU-accelerated focus tilt, elevation, specular sheen, shadows, safely separated adaptive foreground and interruptible rapid D-pad transitions.
- Recent-app list and optional double-Home behavior when OS key delivery permits.
- Contextual Control Center: Controls, active Now Playing, Tools (Recents + Android TV settings). Supported previous/next/play-pause through authorized MediaSessions.
- Top Shelf built-in and selected JSON feed, package-restricted HTTPS deep links; user-adjustable local text size.
- Stable desktop functionality: Dock, manual reordering, folders, wallpaper/photo frame/aerial saver, splash/welcome animation, Standard/Guard OEM safety and updates.

### Verification boundaries

All code may be compiled and signed by the published CI workflow. No physical Sony device results are claimed, no native AirPlay stack is included, and partial Android integrations are not described as Apple platform APIs.

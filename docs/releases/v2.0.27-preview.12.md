# Tigris 2.0.27 Preview 12

- 桌面统一为 16:9 横向卡片：优先使用应用自带品牌 TV banner，没有可用 banner 时使用白底原图标。保留用户手动指定的图标来源。
- 去掉图标白框、光晕和倾斜，选中时放大至 1.12 倍。保留 Dock 液态玻璃。
- 控制中心移除“控制”“快捷操作”标签及对应快捷入口，保留现有电视控制和活动媒体控制。
- 应用切换使用堆叠画面截图；无截图的任务仍可打开，显示明确提示，不用巨大图标冒充画面。菜单键可尝试系统原生切换器。
- 默认选中最近使用的任务，保留正常的深色和黑场截图。

## Packages and verification

Version name: `2.0.27-pre12`; version code: `45`. Standard and Guard APKs retain the stable signing identity. The publishing workflow requires both-flavor unit tests, release builds, lint, installer checks, signature verification and upgrade checks.

Screens are cached accessibility screenshots on Android 11+ with the existing service enabled, not continuously live application surfaces. Missing permission, protected content or unsupported firmware can prevent previews. Native Recents depends on firmware support. App force-stop requires authorized local ADB. This release does not enable permissions automatically.

This is a preview release for user acceptance. No new television installation or hardware verification is claimed. Main remains unmerged.

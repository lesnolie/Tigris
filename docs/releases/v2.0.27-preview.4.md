- **通用图标卡片：** 自动优先高分辨率 Android TV Banner，其次是通过透明度检查可安全分层的 Adaptive Icon，最后是原生图标或 App 名称占位符。特殊横幅保持原比例；不会拉伸、丢弃图案或直接抠图破坏 Logo。
- **品牌颜色：** 优先从 App 自有图像中选取明显颜色，生成内敛、对比度受控的横向渐变；非透明图标保持原有方形内部背景。
- **回退与手动切换：** 主屏幕设置可切回 v2.0.26 统一浅灰底板；也可以试用 Apple tvOS 5:3 / Android TV 16:9 比例。长按每个 App 可指定自动、TV Banner、原生图标或经典样式。
- **GPU 交互：** Android 硬件加速 View + 可中断 Choreographer Tween；方向感知的透视倾斜、缩放/浮起、压低的蓝色光晕、独立阴影与随倾斜的移动高光。Adaptive 前景只有通过安全检查才单独参与视差，其余图标保持完整单层变换。
- **性能：** 仅焦点状态变化时更新渲染姿态；缓存生成的位图，快速遥控器切换不重复解码，不采集 4K 壁纸帧。
- **范围：** Android 9+，标准版和 Guard 版，versionCode 37，versionName 2.0.27-pre4。同一正式签名可按对应类型覆盖 v2.0.26，保留设置。**不修改原厂 HOME、不修改 Xiaomi/TCL 的守护与休眠逻辑。**

## English

- **Universal artwork:** Quality-checked native TV banners, tested adaptive foreground/background layers, intact native icons, and a name-based placeholder for missing resources. No forced stretching or destructive logo separation.
- **Brand card:** Restrained color-coordinated landscape backgrounds, with conservative fallback for fully opaque square icons.
- **Reversible preview:** Original v2.0.26 frost-grey mode remains selectable; compare 16:9 Android TV with 5:3 Apple tvOS shapes. Long-press any app to override its artwork source.
- **Hardware-accelerated focus:** Interruptible directional perspective, scale/lift, tightened shadow, movable specular sheen, optional independently moving validated adaptive foreground; no idle animation loop or per-focus bitmap decoding.
- **Compatibility:** Android 9+, standard and Guard signed with the same stable certificate, versionCode 37 and versionName 2.0.27-pre4. No HOME takeover, OEM sleep, or casting changes.

**Limits:** The supplied X reference clip was not available for frame analysis. Real TV screenshots, gameplay-style recordings, actual GIF and 60 FPS/frame-time acceptance remain outstanding; a passing CI build alone is not proof of performance.

### Test and diagnostics

1. Back up relevant settings before any sideload. Download the APK matching the currently installed Standard/Guard variant. Do not uninstall the existing app to work around signature mismatches.
2. Toggle **App tile appearance** between Auto Brand and Classic; toggle **App tile aspect ratio** 16:9 vs 5:3. Long-press several applications and change their tile artwork source.
3. Rapidly press Left/Right/Up/Down and test no stale-focus jumps or flicker. Verify playback/casting/screensaver and app launch behavior unchanged.
4. To collect real footage from a connected Android TV: `adb shell screenrecord --time-limit 30 /sdcard/tigris-focus.mp4`, then `adb pull /sdcard/tigris-focus.mp4`.
5. Collect package/Window metrics: `adb shell dumpsys gfxinfo com.leslie.tvhome framestats`, and, if supported, a Perfetto FrameTimeline trace. Compare identical wallpaper/settings against v2.0.26.
6. Three screenshots: plain dark, light static 4K, and video wallpaper, captured from actual running application. No AI-generated mockups accepted as evidence.

Open a GitHub issue with the exact model, firmware, screenshots, video and measured frame times. OEM-specific behavior remains unverified.

## Preview 4 new capabilities / 预览版 3 新增功能

- **Recent App Cards / 最近应用：** Control Center, Settings and APP_SWITCH (when delivered to the launcher) show locally recorded recently launched apps. UsageStats enriches history when authorized. **Not real tvOS task snapshots or app force-close.**
- **Installed-App Search / 本地应用搜索：** filter available apps, use an installed Android speech recognizer if supported, or enter text using a temporary token-protected QR-paired LAN keyboard while Search is open. **Not Siri or universal streaming content search.**
- **Now Playing / 正在播放：** Control Center shows authorized MediaSession playback metadata and a play/pause toggle with notification-listener access; otherwise displays unavailable.
- **Local launcher profiles / 三组本地桌面用户配置：** separate user-defined app ordering, hidden apps and recent-first settings. Not Android system accounts or Apple IDs.
- **System Settings / 系统设置：** open Android public display, audio, network, Bluetooth, applications, keyboard, accessibility and time settings, with OEM fallback. Does not silently change device policies.

### Explicit remaining gaps / 仍未完成

- True global OS app-task snapshots, cross-app double-Home interception, global force-close.
- Complete system-wide media search and Siri voice integration; native media-provider Top Shelf for arbitrary third-party apps.
- Real AirPlay receiver and Apple's device Continuity input across other apps (paired keyboard only works in local Tigris Search).
- Cross-app account/profile switching, privileged system settings and fully enforced parental app restrictions.
- Sony BRAVIA physical device capture, actual 60 Hz frame timing, real video/GIF, 4K wallpaper variations and multi-OEM validation.

**This is an intermediate functional preview, not proof that every tvOS 27 feature is implemented or verified.**

## Preview 4 additional changes / 预览版 4 新增

- **Control Center contextual pages:** Controls / Now Playing (appears when Android exposes an active authorized media session) / Profiles. No longer stacks every control offscreen in one tall panel.
- **Media transport:** previous, play/pause and next on the Now Playing page. Previous/next only appear if the current Android MediaSession advertises support.
- **Local app restrictions:** opt-in PIN protects launches initiated through Tigris Home tiles, folders, Search and Recents; salted PBKDF2 credential and five-failure temporary lockout. **Not Android system parental controls:** other launchers, system settings and app deep links outside Tigris may bypass it.
- **Dynamic Text:** switch among 90% / 100% / 115% / 130% in Tigris UI. Does not change other Android apps or Apple's accessibility settings.
- **Double Home:** optional, default off, requires Android to deliver actual Home/key-filter or Home intents to Tigris; Xiaomi guard path is explicitly excluded; no false claim of universal key interception.
- **Top Shelf deep links:** optional HTTPS destination from an explicitly configured custom shelf feed; intent constrained to the linked app package, with safe fallback to normal app launch. Existing image-only feeds keep working.
- **Local profiles:** existing profiles also maintain separate folder collections. Profile 0 keeps its original data and keys.
- **AirPlay receiver integration:** optional separately installed [jqssun/android-airplay-server](https://github.com/jqssun/android-airplay-server), a GPLv3 Android TV receiver app. Tigris can detect/open its installed package and shows the upstream GitHub release QR. **No GPL native libraries or receiver APKs are bundled in Tigris.** The user must choose and install it separately; compatibility depends on sender, DRM, local multicast network, decoder and firmware.

### Real TV acceptance checklist / 真实设备验收

1. On Sony BRAVIA, test Standard in-place upgrade, then verify all controls with the built-in remote.
2. Open Control Center; verify Controls tab remains within TV visible screen, Media tab appears only when media is active, and Profile tab switches local home layouts.
3. Test 30+ installed APKs: TV Banner, ordinary square, Adaptive Icon, transparent logo, unknown package; switch 5:3/16:9 and Classic fallback.
4. Hold Left/Right/Up/Down, spam direction changes, open/close apps, check icon focus and memory usage.
5. Configure PIN and deny/retry a restricted app from Home, folder, Search and Recents; verify system/other-launcher bypass is documented.
6. Open Search QR keyboard from a phone on the same LAN; test token isolation, text limits and server shutdown on page exit.
7. Test Top Shelf custom HTTPS deep link with an app that handles the URL, then test absent handler fallback.
8. If interested in AirPlay, install the separately maintained upstream receiver and test iPhone/iPad/macOS mirror on local network; do not test protected DRM content as a claim of supported playback.
9. Record 30-second actual focus capture: `adb shell screenrecord --time-limit 30 /sdcard/tigris-focus.mp4` then `adb pull /sdcard/tigris-focus.mp4`.
10. Record frame-time distribution and jank using `adb shell dumpsys gfxinfo com.leslie.tvhome framestats` and Perfetto FrameTimeline when supported. Compare against v2.0.26 with dark/light UHD/photo/video backgrounds.

### Still not equivalent to tvOS 27 / 剩余差距

- No privileged Android live task snapshots, cross-app universal task termination, or guaranteed HOME key filtering on every OEM.
- No native Apple AirPlay stack *inside Tigris* or DRM-protected Apple service playback; the optional external receiver has its own compatibility limits.
- No Apple ID or OS account switching, no universal Siri/content indexing or provider-agnostic Top Shelf integration.
- Tigris-specific PIN restrictions are not systemwide Screen Time controls; QR keyboard is Tigris Search only, not Apple Continuity.
- Real Sony device video/screenshot/FPS acceptance and TCL/Xiaomi regression remain unperformed until actual hardware evidence is captured.

**This is a signed intermediate preview, not final complete tvOS 27 parity.** Keep Issue #96 open and Draft PR #97 unmerged.

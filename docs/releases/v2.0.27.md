# Tigris 2.0.27

## 中文

- **横向品牌图标**：桌面统一 16:9 卡片，自动模式优先使用应用自带 TV banner；没有可用 banner 时使用统一白底与原图标。保留用户手动指定的图标来源。
- **选中放大**：移除额外白框、光晕和倾斜，选中卡片放大至 1.12 倍，保留柔和阴影与 Dock 液态玻璃。
- **堆叠应用画面**：左右切换、确定打开，默认选中最近使用的任务。无截图时保留任务并显示提示，不用巨大图标代替画面；深色和黑场截图不再被误删。菜单键可尝试系统切换器。向上移除卡片；关闭应用依赖已授权的本机 ADB。
- **更简洁的控制中心**：移除“控制”“快捷操作”标签和相关快捷入口，保留现有电视控制及活动媒体会话的播放控制。
- **顶部内容与返回焦点**：Top Shelf 支持遥控浏览、打开对应内容，返回桌面时尽量保留原应用位置，减少跳回首项；内容加载使用有界队列与缓存。
- **文字大小**：可选 90%、100%、115%、130%。

画面预览来自 Android 11+ 已开启无障碍服务保存的截图，不是持续运行的实时应用画面。权限缺失、受保护内容或固件限制会导致无预览；Android 9/10 保留任务卡片但不提供这条截图能力。系统原生切换器取决于固件支持，不会自动启用权限。

## English

- **Horizontal brand artwork:** uniform 16:9 cards prefer the app's TV banner in automatic mode; apps without a usable banner receive a white card with their original icon. Manual source overrides remain available.
- **Scale-only focus:** removes added white frames, halos and tilt; selection enlarges the card to 1.12× while retaining soft shadows and the Liquid Glass Dock.
- **Stacked app previews:** Left/Right selects, OK opens, and the newest task is selected first. Missing previews never hide tasks or substitute giant icons. Dark frames remain valid. Menu attempts native Recents; Up removes a card, with app force-stop dependent on authorized local ADB.
- **Simpler Control Center:** removes Controls/Tools tabs and utility rows while retaining existing TV controls and supported active-session media controls.
- **Top Shelf and return focus:** remote content browsing, package-restricted links, bounded artwork loading and improved Home return continuity.
- **Text scale:** 90%, 100%, 115% or 130%.

Previews are cached accessibility screenshots on Android 11+ with the existing service enabled, not continuously live app surfaces. Permissions, protected content and firmware may prevent previews; Android 9/10 retains task cards without these screenshots. Native Recents depends on firmware. No permissions are enabled automatically.

## Packages / 安装包

`versionName=2.0.27`, `versionCode=46`. Use the matching Standard or Guard package to upgrade in place, including from Preview 12 (code 45). Stable signing identity is retained. Do not uninstall to update.

The release pipeline checks both-flavor unit tests, installer contracts, Release builds, Android lint, signatures, checksums and upgrade compatibility before publishing. Earlier device captures illustrate the desktop; no new television installation or device acceptance is claimed for this release.

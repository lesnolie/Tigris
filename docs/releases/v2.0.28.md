# Tigris 2.0.28

## 中文

- **分组的主屏幕设置**：首页只列出分组：主屏幕、外观、壁纸、屏幕保护程序、顶部内容与天气、开机动画、应用、内存与电源、桌面守护与系统。每组是一页短列表，返回时焦点回到刚才进入的那一行；调整文字大小后仍停留在原分组。所有设置项及其保存的值不变，只是换了位置。
- **电视设置合并为一项**：「桌面守护与系统 → 电视设置」按品牌打开电视自带设置（TCL、小米为各自的设置应用，其他为标准 Android 设置）。v2.0.27 中重复的「电视系统设置」快捷页已移除；无法打开时会给出提示。
- **时钟屏保**：「屏保内容」新增「时钟」，与照片、Apple TV 航拍并列。四种样式：霓虹、翻页、液晶、极简，每种都有多种配色并各自记住。可显示秒；不显示秒时冒号一秒一闪。可选飘雪或星光氛围。屏保显示时左右键换样式、上下键换颜色。纯黑背景，画面每分钟轻微移动，减少 OLED 烙印。
- **时钟声音**：霓虹灯亮起时有与闪烁同步的电流声；显示秒时每秒一声，翻页、液晶、霓虹、极简各有不同声音。两者都可单独关闭。所有声音由程序实时合成，不附带录音文件。
- **自定义 App 图标**：长按主屏幕上的 App →「更换图标」，用手机扫码，在手机页面的「App 图标」里上传图片。横版 16:9 图片铺满图标，方形图片居中显示。手机页面可为主屏幕和文件夹里的任意 App 换图标；长按菜单或手机页面都可「恢复默认图标」。Tigris 不附带也不下载第三方 App 的图标。
- **预览入口**：「屏幕保护程序 → 预览」与「时钟 → 预览」可立即查看屏保。

## English

- **Grouped Home Screen Settings:** the main page lists groups only — Home Screen, Appearance, Wallpaper, Screen Saver, Top Shelf & Weather, Boot animation, Apps, Memory & power, Home Guard & System. Each group is a short page; returning focuses the row you came from, and changing text size keeps you in the group. Every setting and stored value is unchanged, only moved.
- **One TV settings entry:** "Home Guard & System → TV settings" opens the TV's own settings through the brand adapter (TCL and Xiaomi settings apps, otherwise standard Android). The duplicate "TV System Settings" shortcut page from v2.0.27 is removed; a message appears when settings cannot be opened.
- **Clock screen saver:** "Screen Saver → Content" adds Clock beside Photos and Apple TV Aerials. Four styles — Neon, Flip, LCD and Minimal — each with several colours remembered per style. Optional seconds; without them the colon blinks. Optional snow or stars. While it shows, Left/Right change the style and Up/Down the colour. Black background with a small drift every minute to reduce OLED retention.
- **Clock sounds:** neon tubes buzz in step with their flicker when they strike up; with seconds shown, a per-second tick that differs by style. Both can be turned off. All sounds are synthesised at runtime; no recordings ship with the app.
- **Custom app icons:** long press an app → Change icon, scan the QR code and upload a picture under App Icons on the phone page. A wide 16:9 picture fills the tile; a square one is centred. The phone page covers every app on Home and in folders; Restore default icon is available from the long-press menu and the phone page. Tigris neither ships nor downloads third-party app icons.
- **Previews:** "Screen Saver → Preview" and "Clock → Preview" show the screen saver immediately.

## Packages / 安装包

`versionName=2.0.28`, `versionCode=47`. Use the matching Standard or Guard package to upgrade in place from v2.0.27 (code 46). Stable signing identity is retained. Do not uninstall to update.

The grouped settings, TV settings entry, all four clock styles and the custom icon flow were checked on a Sony BRAVIA (Android TV) with a build carrying the stable signing identity: navigation and focus return, rendering, the neon strike animation, flip animation, snow, uploading a picture through the phone-page endpoint (from a computer on the same network) and restoring the default from the long-press menu. The clock sounds were not checked by ear. The release pipeline checks both-flavor unit tests, installer contracts, Release builds, Android lint, signatures, checksums and upgrade compatibility before publishing.

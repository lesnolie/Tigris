# Tigris 2.0.29

## 中文

- **修复 HGTV 无法更新**：更新页点 HGTV 时一直报签名不符、装不上。原因是 Tigris 里钉定的 HGTV 签名指纹（`b237b1d3…a0caeaa`）并不是上游的签名证书，而上游 1.3.6.2 与 1.3.7 的实际签名都是 `27da9072…fcee019`，校验采用全等比较，所以这条更新路径从未通过。现已改为上游真实指纹，HGTV 可以正常安装与更新。
- 其它应用与主屏幕行为不变。

## English

- **HGTV updates work again**: tapping HGTV in the updater always failed the signature check. Tigris pinned the fingerprint `b237b1d3…a0caeaa`, but the upstream APKs (1.3.6.2 and 1.3.7) are signed by `27da9072…fcee019`, and the check requires an exact match, so that path never succeeded. The pinned value now matches upstream, so HGTV can be installed and updated.
- No other app or Home behaviour changes.

## Packages / 安装包

`versionName=2.0.29`, `versionCode=48`. Use the matching Standard or Guard package to upgrade in place from v2.0.28 (code 47). Stable signing identity is retained. Do not uninstall to update.

The HGTV fingerprint was verified with `apksigner verify --print-certs` on the published `HGTV_1.3.6.2.apk` and `HGTV_1.3.7.apk` assets; the installed copy on the Sony BRAVIA reported the same certificate. HGTV 1.3.7 was then installed through `adb install -r` and reported `versionName=1.3.7`. The updater path inside Tigris was not re-run end-to-end after this change; note also that upstream kept `versionCode=76` in 1.3.7, identical to 1.3.6.2.

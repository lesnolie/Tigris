# Tigris 2.0.9

## 中文

- 统一电脑端安装策略，AI、自动和手动安装共用设备检测与策略。Sony 原生 HOME、TCL/雷鸟 Guard 与 T-Cast 特殊推送保留既有流程。
- 小米/Redmi 和未知 Android 固件默认只做安全安装与诊断；HOME 接管试验需要单独授权，不禁用原厂桌面或系统设置。
- 广告维护独立于安装；没有经过审查的精确固件证据就拒绝禁用。当前批准表为空，不承诺去除广告。
- 增加通用功能扩展契约及中英文贡献指南。天气仍默认关闭，保留已有天气开关、壁纸、布局、文件夹、动画与守护配置；未修改视觉或品牌运行时适配器。
- 修正 Windows 安装状态目录中的端口冒号问题，统一计划入口与恢复路径；官网在直接 APK 下载旁说明能力限制。

### 现有用户升级

标准版使用 `Tigris-v2.0.9.apk`，Guard 用户使用 `Tigris-guard-v2.0.9.apk`。
包名仍为 `com.leslie.tvhome`，versionCode 从 14 升到 15，继续使用既有官方签名。
直接覆盖升级或通过应用内软件更新，不卸载旧版、不清除数据、不重置原有设置。
本版本继续包含 2.0.8 的 Android 9/10 安装包签名读取修复。
非官方签名构建不能保证直接覆盖官方版；遇到签名冲突应停止，不通过卸载绕过。

发布工作流比较上一正式版与新版两个 APK 的签名、包名、版本递增、Android 要求、
CPU 架构和 HOME 声明，并在全部通过后发布校验文件。
这些是包级升级检查，不能代替真实电视安装。小米实体 Home、冷启动、待机唤醒、
内存清理后恢复、广告变化和性能仍未实机验证，不新增任何型号的“已验证”声明。
电脑端统一入口见 [模块指南](../modules.md)，需下载本版本完整源码及现有工具依赖。

## English

- Shared host-side strategies serve AI, automatic and manual installation. Existing Sony native HOME and TCL/FFalcon Guard/T-Cast paths are preserved.
- Xiaomi/Redmi and unknown Android firmware use safe APK installation and diagnostics by default. HOME trials require separate consent; factory launchers and settings remain enabled.
- Ad maintenance is separate and refuses changes without reviewed exact-firmware evidence. The approved table is empty; no ad-removal claim is made.
- Shared feature contracts and bilingual contribution guides preserve weather opt-in, existing settings, layouts, folders, wallpapers, animations and Guard behavior. Visual algorithms and runtime brand adapters are unchanged.
- Windows state paths now handle serial-port colons consistently. Direct APK download entries explain installation limits.

### Existing installations

Use `Tigris-v2.0.9.apk` for Standard or `Tigris-guard-v2.0.9.apk` for Guard.
The application ID remains `com.leslie.tvhome`, versionCode increases from 14 to 15,
and the existing official signing certificate is retained. Update in place or through
Software Updates; do not uninstall, clear data or reset settings. The 2.0.8 Android
9/10 archive-signature fix remains included. Unofficially signed builds may not update
to official APKs; stop on a signing mismatch rather than uninstalling to bypass it.

Before publication, CI compares both APKs against the previous official release for
signing identity, package ID, increasing version code, Android requirements, CPU
architectures and HOME declarations. These package checks do not prove physical-TV
installation. Physical Home, boot, wake, cleanup recovery, advertising and performance
remain hardware-unverified; no new model certification is claimed. The shared host
entry point requires this release's complete source checkout and documented tools.

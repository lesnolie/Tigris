# Settings 设计检查（2026-10-27）

后续已完成 Settings 玻璃界面、控件语义、弹窗及滚动修复，并与更新页共享默认背景。以下为改版前的审计记录；当前实现和验证见 [settings-glass-validation.md](settings-glass-validation.md)。

对照用户已在 Sony 电视确认的「应用与更新」液态玻璃设计。结论：Settings 的双栏结构和焦点返回行为可以保留，但材质、控件语义、弹窗和滚动边界尚未统一。

## 检查范围与证据

实机：Sony BRAVIA 4K VH2，Android API 31，1920×1080，中文、当前字体与用户现有设置背景。

逐项走过主列表的 41 个不同条目；打开了「释放内存时保留的 App」「隐藏的 App」「已删除的预装 App」三个子页、「天气城市」「安装与 Home 检查」两个弹窗，以及壁纸/手机上传页。只浏览和返回，没有选择应用、切换设置、提交搜索或恢复预装应用。

截图、UI 层级和导航记录位于本机 `C:/work/appletv/.tmp/settings-design-audit-20261027/`，其中 `audit.json` 和 `main-rows.json` 保存焦点与边界。

## 优先处理

### 1. 设置行尚未采用已确认的玻璃材质

事实：右侧设置行未聚焦时只是固定透明色，聚焦时立即换成不透明白色，文字同时改成黑色。没有背景折射、连续高光或关联行照明。左侧大型玻璃图形来自设置背景图片，并不是设置行的实时渲染效果。

- 代码：`SettingsActivity.kt:600`、`SettingsActivity.kt:603`。
- 实机：`main-top.png`、`main-09.png`。
- 建议：以已确认的更新页为材质基准，复用折射与焦点动画；保留用户设置背景和自定义图标。
- 实现约束：Settings 背景使用自己的放大/平移矩阵（`placeBackdrop`），玻璃必须采样实际显示位置；不能把原图直接按更新页的中心裁切方式采样，否则纹理会错位。

### 2. 聚焦行在滚动边缘被裁切

事实：从「上传头像」等条目开始，选中行经常紧贴屏幕底边。以「控制中心样式」为例，焦点边界为 `[909,974][1792,1080]`，选中白块底部圆角被切掉；上缘旧行也出现硬截断。多个分组均复现。

- 代码：`SettingsActivity.kt:120` 的 ScrollView、`SettingsActivity.kt:609` 的放大；没有更新页那样的完整行 reveal 逻辑。
- 实机：`main-09.png`、`main-19.png`、`main-24.png`、`main-29.png`。
- 建议：按完整行和放大范围滚动，保留上下安全距离；内容只在列表视口内裁切，边缘做柔和过渡。

### 3. 不同类型的控件共用同一模板

事实：「显示右上角头像」「天气卡片」「待机时自动释放内存」等开关只显示文字「开/关」，与进入下一页或执行动作的行外观几乎相同。应用选择页只有名称和文本勾号，没有图标，UI 节点没有可勾选/已勾选语义。

- 代码：`SettingsActivity.kt:582` 的通用 row、`SettingsActivity.kt:503` 的应用选择。
- 实机：`main-09.png`、`sub-keep.png`、`sub-hidden.png`。
- 建议：开关使用更新页那种明确的开关轨道；子页入口统一箭头；应用选择使用图标、名称和独立勾选状态，并暴露无障碍勾选语义。

### 4. 弹窗与页面材质断开

事实：城市输入、安装检查使用默认 Android 灰色矩形弹窗。城市输入的确认按钮还重复显示整句「输入城市名称搜索」，与占位提示重叠，主操作不够简洁。

- 代码：`SettingsActivity.kt:541`、`SettingsActivity.kt:459`；城市搜索结果列表在 `SettingsActivity.kt:556`，同样使用默认 AlertDialog。
- 实机：`dialog-city.png`、`dialog-home-check.png`。
- 建议：应用自有弹窗统一为玻璃面板、清楚的标题/说明层级和明确的取消/确认焦点；城市主操作简化为「搜索」。电视系统键盘属于系统界面，保留其原生交互。
- 限制：没有提交城市搜索，结果列表只做代码检查。

### 5. 空状态和只读信息伪装成可操作项

事实：「已删除的预装 App」为空时，「没有已删除的 App」仍是能获得焦点的白色大按钮，点击回调没有动作。「关于」也是可聚焦、可点击但没有动作的行。

- 代码：`SettingsActivity.kt:516`、`SettingsActivity.kt:493`。
- 实机：`sub-removed.png`、`main-bottom.png`。
- 建议：空列表显示说明性空状态；版本号作为只读信息，或为「关于」提供真实详情页。焦点保留给实际操作与必要的返回入口。

## 后续排版统一

- Settings 页头居中、说明置于大型装饰图下方，与更新页的左侧标题/说明规则不同。统一页头、字号层级、圆角、行距和分组间距。
- 当前分组标题、设置值和说明在蓝绿色亮部偏淡，需按实际背景维持可读性，不能只给白字降低透明度。
- 41 个条目集中在一条长列表，跨分组查找成本较高。可先增加清楚的分组导航，再考虑独立分类页面。
- 壁纸/上传页当前使用纯深色底、白色焦点描边和蓝色勾号，尚未共享新材质与焦点规则；保留图片预览清晰度和二维码的黑白对比，玻璃用于导航/操作区域。

- 三个应用子页返回主页面后，焦点都回到原入口。

## 验证边界

这是设计检查，未修改或部署 Settings 代码。未实测 Settings 的英文、大字体、无背景图模式或其他电视型号；长文本和无背景材质回退需要在后续实现时单独验收。未执行系统设置变更、清理内存、开关守护、重启或待机。

建议实施顺序：共享设置行与滚动边界 → 开关/应用选择/空状态 → 自有弹窗 → 统一页头和分类导航 → 壁纸/上传页操作区域。

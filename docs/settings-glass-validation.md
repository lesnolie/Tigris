# Settings 液态玻璃改版验证（2026-10-27）

## 行为和设计

- 保留双栏布局，左侧标题、当前项说明和返回按钮；右侧分组列表统一使用折射玻璃、白字及连续焦点高光。
- 开关采用可视滑块；应用选择页增加图标和独立勾选，并提供可勾选/已勾选的无障碍信息。
- 城市输入、安装与 Home 检查、关于和城市结果统一使用玻璃弹窗。空列表提供说明，将焦点留给返回按钮。
- 主列表滚动会留出完整选中行的上下空间；严格限定列表视口，边缘淡出，兼容中英文及大字体。
- Settings 与应用/更新页默认共用 `SettingsBackdrop.load`：当前缓存的主屏幕壁纸或内置主题，经柔化和压暗显示。默认不再依赖单独下载的设置背景图；已下载文件不删除。用户上传的设置背景和图标仍可使用，原偏好键保留。

## 滚动底色跳动修复

旧实现把背景采样烘焙到每一行的位图。滚动时旧纹理跟随行移动，80 毫秒防抖又会等滚动停止才重新采样，产生停顿和跳色。这种视觉不连续不一定体现为系统掉帧。

Settings 现在使用 `MovingGlass`，每次绘制按实际屏幕坐标更新纹理网格，由图形处理器（GPU）连续采样固定背景并在边缘折射。高光只按控件形状生成并缓存，不随滚动重算。更新页继续使用原有烘焙材质，共用的背景准备流程与原逻辑相同。
